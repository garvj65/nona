Keyboard compatibility and focusThis starter targets keyboard-controlled games. Click the game canvas if necessary. Switching to another application disables keyboard mode; switching tabs inside the same browser window may not, so stop control before doing that. Gamepad-only games need a future virtual-controller adapter. The wheel steers proportionally in NONA Sprint. For other games, the keyboard bridge produces left/right key presses. Tilt controls and a virtual gamepad are future milestones.
