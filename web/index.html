Optional Xbox setup

Keyboard and the included demos need no driver. Xbox output needs the optional Python adapter plus a separately installed ViGEmBus driver. ViGEmBus is retired upstream; future Windows compatibility is not guaranteed.

Read the setup guide, run SETUP_XBOX_OUTPUT.bat, then follow the guide for the driver. NONA's normal launcher does not install it.

Keyboard compatibility and focusThis starter targets keyboard-controlled games. Click the game canvas if necessary. Switching to another application disables keyboard mode; switching tabs inside the same browser window may not, so stop control before doing that. Xbox output is available as an optional adapter after its separate setup. The wheel steers proportionally in NONA Sprint. For other games, the keyboard bridge produces left/right key presses. Tilt and mouse-only input remain future milestones.
